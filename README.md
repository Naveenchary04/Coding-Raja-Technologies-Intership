## Title
Blogging Platform
A Full-Stack Blogging System built using modern web technologies. This platform allows users to create, edit, delete, and view blog posts with user authentication, rich text formatting, and social sharing options.

##  Features

-  User registration and login (authentication system)
-  Create, edit, delete blogs with rich text editor
-  Comment system for each blog post
-  Social media sharing (Twitter, Facebook, LinkedIn)
-  Search and filter blog posts
-  User dashboard to manage posts
-  Role-based access (Admin/User)

---

##  Tech Stack

**Frontend:**
- HTML5, CSS3
- JavaScript
- Bootstrap / Tailwind (optional)

**Backend:**
- Node.js
- Express.js

**Database:**
- MongoDB
- Mongoose ODM

**Other Tools:**
- bcrypt (password hashing)
- JWT (JSON Web Token for secure auth)
- Multer (for image upload)
- EJS or React (choose based on your actual tech)
